## What I learned
- Regex is a pattern-matching mini-language for text. It searches, extracts, and substitutes — it does not sort or analyze.
- The `r` prefix on a string is a Python feature (raw string), not a regex feature. It tells Python to leave backslashes alone so regex can interpret them itself. Same prefix is useful for Windows file paths.
- `\d` matches exactly one digit character (0–9). `\d+` is for "one or more" — that's a quantifier I'll learn tomorrow.
- Senior-level explanations are surgical: ≤3 sentences, name the concept, name the trade-off or limit. Verbosity is a confidence-defense pattern, not a knowledge problem.
- Regex is a scalpel. The moment a problem becomes about meaning rather than shape, hand off to other tools (Counter, datetime, etc.). This was the gap I had on Task E of the diagnostic.
